# SunPlayer

SunPlayer is a desktop HDR video player for Windows, macOS, and native
Wayland Linux. It uses FFmpeg for media decoding, libplacebo for video color
processing, Qt Quick for the player scene, and a platform QRhi backend for
presentation.

The project is under active development. Platform requirements, validated
dependency versions, build commands, and packaging behavior are documented in
[the build subsystem](docs/subsystems/build/README.md).

## Help and diagnostics

Use **Report a bug…** or **About SunPlayer** from the player's `…` menu. See
[the privacy policy](PRIVACY.md) for how local diagnostics are handled.

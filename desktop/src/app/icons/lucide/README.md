# Lucide application icons

This directory contains a minimal subset of Lucide 1.28.0 from the official
release archive. The SVG strokes are pinned to Sunroom's light control-icon
color instead of Lucide's CSS `currentColor` so Qt's SVG renderer produces the
same monochrome result in packaged QML resources.

Source: https://github.com/lucide-icons/lucide/releases/tag/1.28.0
